# XeroChunks Portfolio

Your Garry's Mod developer portfolio is live at:

**https://prismarinechunks.github.io/gmod-portfolio/**

## Setup Instructions

To enable GitHub Pages for this repository:

1. Go to your repository settings: https://github.com/prismarinechunks/gmod-portfolio/settings
2. Scroll down to **Pages** section
3. Under "Source", select **Deploy from a branch**
4. Select **main** branch and **/ (root)** folder
5. Click **Save**

Your site will be live in a few seconds at `https://prismarinechunks.github.io/gmod-portfolio/`

## Features

- **Android 4 Holo-Inspired Design** - Authentic retro aesthetic with cyan accents
- **Responsive** - Works on desktop and mobile
- **Real Project Links**:
  - PvZ Plants vs Zombies NPCs (Steam Workshop)
  - XBase/DrGBase Framework (GitHub + Steam Workshop)
- **Smooth Animations** - Hover effects and scroll transitions
- **Easy Customization** - Clearly marked placeholders for:
  - Profile images
  - Project screenshots
  - GitHub URLs
  - Discord links
  - YouTube channel

## Customization

Edit `index.html` to replace placeholder URLs marked with `<!-- REPLACE: -->` comments.

### Key placeholders:
- `https://github.com/YOUR_USERNAME` - Your GitHub profile
- `YOUR_STEAM_ID` - Your Steam ID for Workshop link
- `YOUR_DISCORD_INVITE` - Your Discord server invite
- `YOUR_CHANNEL` - Your YouTube channel (optional)

All styling is in `style.css` and interactive features are in `script.js`.
